# 工业机械臂运动模拟器

## 项目简介

工业机械臂运动模拟器是一个专业的可视化工具，用于模拟工业机械臂在不同坐标系下的运动和定位。该模拟器支持多坐标系管理、点坐标转换、机械臂参数调整等功能，适用于工业自动化领域的教学、研究和开发。

## 核心功能

### 1. 多坐标系管理
- 支持创建和管理多个坐标系（世界坐标系、图像坐标系等）
- 每个坐标系可独立设置原点位置、旋转角度和缩放比例
- 实时可视化显示各坐标系的坐标轴和网格

### 2. 坐标点转换
- 支持单点坐标在不同坐标系间的相互转换
- 批量坐标点转换和管理
- 点的可视化显示，包含角度方向指示

### 3. 机械臂运动模拟
- 可视化机械臂模型，支持调整旋转角度和半径
- 实时显示抓手位置坐标和角度
- 支持多种角度范围模式（0~360度、-360~360度、-180~180度）

### 4. 交互功能
- 双击画布创建坐标点
- 鼠标拖拽移动坐标系和机械臂
- 滚轮缩放视图
- 实时参数调整和可视化更新

## 技术特点

### 角度定义标准
- **角度正方向**：x轴正方向指向y轴正方向
- **0度方向**：指向x轴正方向
- **-90度方向**：指向y轴正方向

### 坐标系转换
- 支持任意旋转角度的坐标系间转换
- 实时坐标计算和可视化更新
- 自动验证坐标系XY轴垂直性

### 数据管理
- 场景保存和加载功能
- 坐标点导入导出功能
- 实时日志记录和错误提示

## 使用指南

### 基本操作
1. **创建坐标系**：在"坐标系设置"标签页中，填写参数后点击"添加坐标系"
2. **添加坐标点**：在画布上双击鼠标左键创建点
3. **调整机械臂**：在"机械臂设置"标签页中调整参数，或使用方向键移动
4. **坐标转换**：在"坐标点转换"标签页中进行单点或批量转换

### 角度范围设置
- 在机械臂设置中选择角度范围模式：
  - `0~360度`：标准工业角度范围
  - `-360~360度`：扩展角度范围
  - `-180~180度`：数学角度范围

### 场景管理
- 使用菜单栏的"文件"选项保存或加载场景
- 场景文件自动保存在用户目录下的`.robot_arm_simulator/scenes/`文件夹中

## 注意事项

1. **坐标系验证**：系统会自动检查坐标系XY轴的垂直性，非垂直坐标系可能导致转换误差
2. **性能优化**：画布平移、缩放等使用 Matplotlib 的 `draw_idle` 合并重绘；拖拽坐标系/机械臂时对全量重绘限频（约 55Hz），松手后仍会完整刷新；大量坐标点时可适当缩小视图范围
3. **数据安全**：建议定期保存场景数据，避免意外关闭导致数据丢失

## 故障排除

### 常见问题
1. **画布无法显示**：检查Matplotlib和PyQt5安装是否正确
2. **坐标转换错误**：确认坐标系参数设置正确，特别是角度值
3. **程序响应缓慢**：减少同时显示的坐标点数量，或调整视图范围
